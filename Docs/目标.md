# FretReflect

指映 (FretReflect) — 指板映像，一目了然

本项目服务于我个人，作为一个吉他初学者，甚至最乐理也是不清楚
需要提供一个清晰的，可视化的网页，帮助我直观看到
- 基础8度中，有哪几个音
- 木吉他的6个弦空弦音
- 木吉他每个品，分别是什么音
- 常见和弦，分别是哪几个音
- 常见和弦在木吉他上，分别是怎么按的

----

记住，美观是非常重要的

----

要求使用vite构建，端口为3002，允许局域网访问
样式使用tailwindcss
图标使用lucide图标库
如果有必要的2D渲染工作，可以使用PixiJS进行2D渲染
其它技术栈由你决定
